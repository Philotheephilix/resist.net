How ResistNet works

Detection from the inside.
Evidence on-chain.

Volunteer Nodes

Run on any device. Probes originate from inside India, on Indian ISPs — catching ISP-level blocks that external monitors miss entirely.

On-Chain Evidence

Every result signed by the node's wallet. Timestamped on Arkiv. Permanent. Government cannot delete the record of when a shutdown started, how long it ran, or what method was used.

Live Dashboard

24-hour availability charts per site, per region, per ISP. Block type detection: DNS poisoning, TCP reset, HTTP block, TLS-SNI interference. Test any URL in seconds.
