Internationalization (i18n)

Localize country names and sorting across components like PhoneField and CountryDrawer.

SSR Locale Registration

For SSR applications (Next.js, Remix, etc.)

Use loadLocale helper and I18nProvider to ensure proper hydration:

import { I18nProvider, loadLocale } from "@worldcoin/mini-apps-ui-kit-react";

export default async function Page({ searchParams }) {
  const locale = searchParams.locale || "en";
  const localeData = await loadLocale(locale);
  return (
    <I18nProvider localeData={localeData}>
      {/* Your components */}
    </I18nProvider>
  );
}
Client-Side Locale Registration

For client-side only applications

Import only the locales you need and register them once during app initialization.

import { i18n } from "@worldcoin/mini-apps-ui-kit-react";
import fr from "@worldcoin/mini-apps-ui-kit-react/locales/fr.json";
import ar from "@worldcoin/mini-apps-ui-kit-react/locales/ar.json";

// Register at app startup
i18n.registerLocale(fr);
i18n.registerLocale(ar);
PhoneField with Locale (fr)
import { PhoneField } from "@worldcoin/mini-apps-ui-kit-react";

export function ExampleFR() {
  return (
    <PhoneField
      locale="fr"
      label="Téléphone"
      placeholder="06 12 34 56 78"
    />
  );
}
CountryDrawer with RTL Locale (ar)
import { CountryDrawer } from "@worldcoin/mini-apps-ui-kit-react";

export function ExampleAR() {
  return (
    <CountryDrawer
      locale="ar"
      dir="rtl"
      title="الدولة"
    />
  );
}
Notes — Best Practices

Notes

  • Register each locale once per app lifecycle before rendering.
  • Use valid BCP 47 tags: "en", "fr", "ar".
  • SSR: always wrap in I18nProvider to prevent hydration mismatches.
  • loadLocale uses static imports — SSR-safe and bundler-friendly.
What Gets Localized

What gets localized?

  • Country names and alphabetical grouping/sorting in selectors.
  • UI strings are controlled by props — pass your own:
    • PhoneField: label, placeholder
    • CountryDrawer: title, searchLabel

Spacing

4px base grid system. All spacing, sizing, padding, and margin values are multiples of 4px. Defines rules for main content padding (24px), section gaps (40px), subheadline gaps (16px), button-to-iOS-bar (32px), button-above-keyboard (24px), bottom-menu-to-bar (20px), and main-title safe area (64px).
